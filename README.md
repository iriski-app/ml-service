# ИрискИ: Оценка рыночного риска и стресс-тестирование облигаций

Комплексный пайплайн для автоматизированного сбора исторических данных с Московской биржи (MOEX ISS), очистки датасета, финансового инжиниринга (расчет дюрации, выпуклости) и построения моделей машинного обучения для оценки изменения стоимости портфеля облигаций под воздействием параллельных шоков кривой доходности.

---

## Структура проекта

Проект разделен на два взаимосвязанных аналитических этапа (Jupyter Notebook / Python-пайплайна):

1. **Пайплайн 1: Сбор и очистка данных (`full_bonds_dataset.csv`)**
   * Загрузка исторических данных по облигациям через MOEX ISS API.
   * Интеграция данных по ключевой ставке ЦБ РФ и кредитным рейтингам эмитентов.
   * Контроль качества данных, фильтрация аномалий и формирование итогового чистого датасета (82 567 строк).

2. **Пайплайн 2: Финансовый анализ, стресс-тестирование и ML**
   * Расчет срока до погашения ($T$), модифицированной дюрации ($\text{DurationMod}$) и выпуклости ($\text{Convexity}$).
   * Генерация сетки параллельных шоков кривой доходности от $-200$ до $+200$ б.п. (10 сценариев).
   * Расчет процентного и рублевого изменения стоимости портфеля (`target_rub_change`).
   * Строгая валидация с разделением выборки по уникальным тикерам (`SECID`, Group Split 80/20) для предотвращения утечки данных.
   * Обучение базовых моделей (линейная регрессия, квадратичная модель с учетом выпуклости) и алгоритма градиентного бустинга (`CatBoost`).

---

## Основные результаты и метрики

* **Качество данных:** Итоговый датасет содержит более 82 тысяч записей с нулевыми пропусками по ключевым полям (`TRADEDATE`, `SECID`, `CLOSE`, `FACEVALUE`, `MATDATE`, `key_rate_pct`).
* **Сравнение моделей (на тестовой выборке):**
  * **Линейный бейзлайн:** $\text{MAE} = 746.60\text{ руб.}$, $\text{RMSE} = 759.23\text{ руб.}$[cite: 1]
  * **Квадратичная модель (с учетом выпуклости):** $\text{MAE} = 747.49\text{ руб.}$, $\text{RMSE} = 1047.49\text{ руб.}$[cite: 1]
  * **CatBoost (с учетом индивидуальных характеристик облигаций):** $\text{MAE} = 5.87\text{ руб.}$, $\text{RMSE} = 14.98\text{ руб.}$[cite: 2]
* **Вывод:** Модель градиентного бустинга демонстрирует кардинальное превосходство над классическими аналитическими формулами, обеспечивая высокую точность прогнозирования изменения стоимости портфеля при стресс-тестировании.
