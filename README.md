# ИрискИ: восстановление метрик облигаций

Рабочие ноутбуки находятся в `notebooks/price_imputation/`.
Источник данных - MOEX ISS, история TQOB/TQCB с 2022 года.

## Запуск

```sh
python -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
```

Выберите .venv как ядро Jupyter и выполняйте ноутбуки по порядку.
Таблицы и графики сохранены в выполненных ячейках.
Данные и модели находятся в data/ и не входят в Git.

## Состав проекта

1. `01_moex_collector.ipynb`: загрузка истории и выплат, проверка расчётов,
   подготовка целей и признаков. Для повторного запуска используются локальные данные.
2. `02_eda.ipynb`: пропуски, распределения, дни без сделок, простой baseline доходности,
   скользящие окна, волатильность и корреляции на разных лагах.
3. `03_catboost.ipynb`: две модели для дюрации и выпуклости, сравнение с медианами,
   проверка по времени и новым эмитентам, интервалы, DV01 и сохранение моделей.
   Доходность служит входным признаком, если она известна; режим без неё также проверяется.
   DV01 рассчитывается по восстановленным метрикам и стоимости позиции.

В первом ноутбуке REFRESH_HISTORY обновляет историю, REFRESH_REFERENCE обновляет
справочники, графики выплат и календарь. Первичная загрузка дольше повторного расчёта.
Выводы написаны обычными Markdown-ячейками по сохранённому запуску.

## Проверка модели

Первые 65% дат используются для обучения, следующие 10% для выбора числа деревьев,
следующие 10% для калибровки интервалов, последние 15% для проверки.
20% корпоративных эмитентов полностью исключены из обучения, подбора и калибровки.
Test не используется для настройки. Идентификаторы не входят в признаки.
Известные значения не заменяются предсказаниями.

Основные результаты находятся в catboost_metric_scores.csv, catboost_interval_scores.csv,
catboost_dv01_scores.csv и catboost_test_predictions.parquet внутри data/.
Кандидаты заполнения выгружаются отдельно в metric_imputation_candidates.parquet.
Модели и описание признаков сохраняются в data/models/.

На поздних датах MAE дюрации составляет 0,0910 года, MAE выпуклости - 0,4076 лет².
Это примерно на 74% и 79% ниже ошибки групповой медианы. Покрытие интервалов
составляет 74,0% и 75,4% вместо номинальных 80%. Подробный анализ приведён
в конце третьего ноутбука.

## Использование с БД

Сервис может читать характеристики облигации из БД, восстанавливать недостающие
метрики сохранёнными моделями и рассчитывать изменение риска по параметрам сделки.
Для этого нужны схема БД, правила проверки свежести данных и формат результата.
Подключение к реальной БД пока не реализовано.

Текущая модель не выбирает выгодные сделки и не предсказывает будущую цену.
Для рекомендаций нужны отдельные правила по риску, доходности, ликвидности,
комиссиям и ограничениям портфеля.

## Ограничения

Выпуклость рассчитана по выплатам, а не получена как независимый биржевой ответ.
Текущие справочники ограничивают историческую достоверность; часть погашенных
выпусков отсутствует. Календарь 2022 года неполон, эти строки исключены из обучения.
Флоатеры, структурные бумаги и неизвестные будущие купоны не входят в основную модель.
Проверка на отобранных наблюдениях не гарантирует ту же точность для любых реальных
пропусков. Интервалы пока не дают заявленного покрытия во всех режимах.
